# Sources — canonical URLs

Reference list of canonical URLs for every named org, programme, fund, advisor, or resource in this skill.

**How to use this file:** When you need to provide a specific URL to the user, look it up here. Always pair the URL with an instruction to verify current details at source — programme structures, cohort timings, application windows, role openings, and other specifics change continually and many of these sites are JavaScript-rendered (so even Claude's runtime web access may not see current content).

**Source quality discipline:** This file gives canonical URLs, not specific claims about programmes. For any programme, the durable claim is "this org exists, this is what it's broadly for, this is the URL." Specific cohort details belong at source.

## How to handle URLs in responses

When recommending a programme, org, or service, provide:

1. The name
2. One sentence on what it is (durable framing only — not cohort details)
3. The canonical URL from this file
4. An instruction to verify current details at source

**Good:** "Tarbell Center for AI Journalism runs newsroom placement fellowships for AI reporting. Verify current cohort and application details at https://www.tarbellcenter.org/."

**Avoid:** "The Tarbell Fellowship is a 9-month programme..." — this commits to specifics that may go stale. Send the user to the URL.

## Notes on URL staleness

If a URL appears not to work or the org has rebranded:

- Use the AISafety.com aggregator (https://aisafety.com/) to find current canonical URLs

- When in doubt, say so: "I have this URL but you may want to verify it's still current via AISafety.com."
